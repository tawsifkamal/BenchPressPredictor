# Repository Explorer

This is a simple single-page web application that allows you to explore public GitHub repositories.

## Features

*   Fetches and displays a list of public repositories from the GitHub API.
*   Simple and intuitive user interface.
*   Built with vanilla JavaScript, HTML, and CSS.

## Getting Started

To get started with this project, simply open the `index.html` file in your web browser. No special installation or build steps are required.

## Technologies Used

*   HTML
*   CSS
*   JavaScript
