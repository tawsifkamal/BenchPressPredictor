# BenchPressPredictor

This project predicts your one-rep max for the bench press based on your current training data.

## About The Project

This project is a simple tool to help you track your strength progress and predict your one-rep max. It's built with Python and uses a simple linear regression model.

## Getting Started

To get a local copy up and running follow these simple steps.

### Prerequisites

* python

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/your_username_/BenchPressPredictor.git
   ```
2. Install dependencies
   ```sh
   pip install -r requirements.txt
   ```
