# Bench Press Predictor

A simple web application to predict your one-rep max (1RM) for the bench press based on the weight you can lift for a certain number of repetitions.

## How to Use

1.  Open `index.html` in your web browser.
2.  Enter the weight you lifted in pounds.
3.  Enter the number of repetitions you performed.
4.  Click "Predict 1RM" to see your estimated one-rep max.

## How It Works

This application uses the Epley formula to estimate your 1RM:

`1RM = weight * (1 + reps / 30)`
