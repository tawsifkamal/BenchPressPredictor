# CS1332 Data Structures Portfolio

This repository contains implementations of various data structures for a CS1332 course. The goal of this project is to create a portfolio of well-documented and well-tested data structures.

## Data Structures

### SinglyLinkedList

A singly linked list is a linear data structure where each element is a separate object. Each element (a node) contains a reference to the next node in the sequence.

#### Implemented Methods

* `addFirst(T data)`: Adds a new element to the front of the list.
* `addLast(T data)`: Adds a new element to the end of the list.
* `removeFirst()`: Removes and returns the first element from the list.
* `size()`: Returns the number of elements in the list.
* `isEmpty()`: Returns true if the list is empty, false otherwise.
